 PHASE 3: TEXT FITTING ENGINE
================================================================

New files to create:
  src/layout/textFitEngine.ts

Files to modify:
  src/photoshop/textReplacement.ts

textFitEngine.ts exports:
  fitTextToRegion(document, layer, text, region: TextRegion)
    Steps:
      1. Set text content
      2. Refresh Photoshop (read actual bounds)
      3. If width overflows -> reduce font 1pt -> retry
      4. If height > maxLines -> reduce font -> retry
      5. If still overflow at minFontSize -> convert to paragraph text
         with bounded region, retry
      6. Adjust leading to font_size * 1.2
      7. Reposition inside region after resize
      8. Preserve alignment
      9. Return { success, finalSize, lineCount, overflow }

  readActualBounds(document, layerId)
  convertToParagraphText(document, layer, region)

TextRegion presets per role:
  HEADLINE:    maxLines=2, minFontSize=18, maxFontSize=120, center
  SUBHEADLINE: maxLines=2, minFontSize=12, maxFontSize=48,  center
  FEATURES:    maxLines=3, minFontSize=10, maxFontSize=36,  left
  ADDRESS:     maxLines=2, minFontSize=8,  maxFontSize=24,  center
  FOOTER:      maxLines=2, minFontSize=8,  maxFontSize=20,  center
  DATE:        maxLines=1, minFontSize=10, maxFontSize=36,  center
  PHONE:       maxLines=1, minFontSize=8,  maxFontSize=20,  center
  SCHOOL_NAME: maxLines=1, minFontSize=12, maxFontSize=48,  left
  ACADEMIC_YEAR:maxLines=1, minFontSize=10, maxFontSize=24, center
